# SleekReels Pro - 調色字幕核心維護防錯紀錄

本文件專門用來記錄在純前端 `HTML5 Video/Audio` 與 `Canvas` 高階影音互動中，所遭遇到的各類核心同步與解析度不匹配錯誤。後續維護此專案時，必須嚴格遵守以下指標：

---

## 🚨 重大功能異常與深度修復日誌

### 1. 檔案分拆後「影片導入不了 / 卡住」
* **錯誤主因**：由於原單一檔案長度過大，進行局部拆解時，舊程式中負責主導網頁畫布渲染曲線的 `startCanvasRenderLoop` 函式、`redrawPreviewAndLabels` 重繪引擎以及 `updateTimelineUI` 刻度連動方法不小心被平台截斷抹除。這導致影片的 `loadedmetadata` 事件在呼叫這些方法時發生了 `ReferenceError` 阻斷，使得渲染線程徹底當機。
* **解決方案**：在 `utils.js` 的底層全域空間中，將這兩個核心畫布更新循環方法強制補齊並與 `window` 完全同步；在 `app.js` 頂層重新宣告 DOM 物件指標。

### 2. DJI Rec.709 Cube 官方調色檔導入失敗
* **錯誤主因**：大疆官方運動相機 (OSMO Action / Mavic Pro) 導出的 `.cube` 3D LUT 數值字元分割是以 `Tab (\t)` 進行排列，且開頭附帶了 DaVinci Resolve 生成的隱形 **UTF-8 BOM 檔頭 🪙**（`\uFEFF`）。舊解析器因使用單一空格符分割且未排除特殊標頭，讀取時直接長度不匹配而崩潰。
* **解決方案**：在 `parseCubeLUT()` 入口處增加 `text.replace(/^\uFEFF/, "")` 清除 BOM 頭。改用萬能正則 `/[\s,]+/` 分割符（完美相容 Tab 與多重連續空格），並導入防禦性純數字行正規過濾驗證。

### 3. 變更字幕起訖時間，字體無預警「瞬間消失」
* **錯誤主因**：當使用者手動修改字幕相對時間時，畫布指針（Playhead）依然停留在先前的原始時間點上。若新設定的時間範圍不包含當下的指針秒數，渲染核心會認定「此時文字不應顯現」，直接隱藏文字，造成功能失效的錯覺。
* **解決方案**：在 `app.js` 的相對時間變更監聽器中，新增**「智慧自動尋軌播放（Auto-Seek）」**功能。一旦修改出現時間，影片指針會瞬間跟著瞬移跳轉至該起點；一旦修改消失時間，則會精準前移至消失前 0.1 秒處，保證文字在預覽畫面中 100% 保持清晰可見。
