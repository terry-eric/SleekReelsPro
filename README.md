# SleekReels Pro

SleekReels Pro 是一個純前端的直式 Reels 影片編輯器。影片、音樂、字幕、調色和匯出都在瀏覽器本機處理，不需要後端伺服器，也不會把素材上傳到外部服務。

目前專案適合用來快速製作 9:16 手機短影片，支援本機影片預覽、剪輯時間軸、字幕段落、背景音樂、內建 LUT 風格濾鏡，以及依照原影片規格進行瀏覽器錄製匯出。

## 專案檔案

```text
index.html   # 主要頁面與 UI 結構
styles.css   # 響應式版面、手機預覽、控制列樣式
app.js       # 影片載入、預覽、字幕、音訊、匯出邏輯
README.md    # 使用說明
```

## 建議環境

- 建議使用 Chrome 或 Edge。
- 需要瀏覽器支援 `canvas.captureStream()`、`MediaRecorder`、`captureStream()` 等影音 API。
- 頁面使用 Tailwind CDN、Google Fonts、Font Awesome CDN；第一次開啟時需要網路載入樣式與圖示。
- 影片處理完全在瀏覽器本機進行，4K 或高碼率素材會比較吃 CPU、GPU 和記憶體。

## 啟動方式

建議用本機靜態伺服器開啟，不要直接用 `file://` 開檔案。

```powershell
cd C:\Users\user\Desktop\test
python -m http.server 8787
```

接著用瀏覽器打開：

```text
http://127.0.0.1:8787/index.html
```

如果 Python 沒有安裝，也可以用 VS Code Live Server 或任何靜態網頁伺服器，只要能服務 `index.html`、`app.js`、`styles.css` 即可。

## 基本使用方法

1. 開啟頁面後，點選上方或手機預覽中的上傳區，選擇原始影片。
2. 載入後可用手機預覽上方的按鈕更換影片、旋轉影片，或切換模擬 Reels 介面。
3. 在時間控制區輸入影片起點與終點，也可以拖曳時間軸上的剪輯框。
4. 剪輯範圍最短為 1 秒；可以拖曳整段剪輯框在影片範圍內平移。
5. 按播放按鈕確認預覽效果。
6. 完成後到匯出區，確認來源解析度、來源幀率、來源碼率，按下匯出按鈕。

## 字幕與文字

- 右側數字按鈕代表字幕段落，點選後會跳到該段時間並開啟文字編輯。
- 手機版會從預覽畫面底部彈出文字編輯抽屜，方便直接調整內容。
- 可以設定文字內容、大小、顏色、描邊、黑底、位置、對齊方式與動畫。
- 預覽畫面上的字幕可以直接拖曳移動。
- 開啟「接續」後，新增文字段落會依照時間順序接在前一段後面。
- 可使用複製與刪除按鈕快速管理段落。

## 調色與 LUT 風格

右側色塊是內建調色風格。點選色塊後會套用到預覽與匯出。

目前內建風格包含：

- 原始
- 電影 Teal
- 黃昏暖色
- 賽博霓虹
- 黑白高對比
- 冷綠森林
- Clean 709
- Soft Film
- Vivid Pop
- Cool Matte

目前版本不支援再新增外部 LUT 檔案。

## 音樂與音訊

- 手機預覽右下角的音樂圖示可以上傳背景音樂。
- 載入音樂後，可以調整原聲音量與音樂音量。
- 音樂時間軸可以選擇使用哪一段音樂，並跟影片剪輯長度同步。
- 匯出區的 Dynamic Limiter 可以降低爆音風險，但它不是萬能修復；如果原音或音樂已經嚴重破音，仍建議先降低音量。

## 匯出說明

- 匯出解析度會跟隨原影片解析度。
- 匯出幀率會優先跟隨偵測到的原影片 FPS，偵測不到時 fallback 為 30 FPS。
- 匯出碼率會依照原影片平均碼率估算，並扣除音訊預留空間。
- 瀏覽器若支援 MP4/H.264 MediaRecorder，會優先輸出 MP4。
- 若瀏覽器不支援 MP4 錄製，會自動改輸出 WebM。
- 匯出時請盡量保持頁面在前景，避免瀏覽器背景節流造成錄製不穩。

## 常見問題

### 打開後樣式或圖示不完整

確認網路可連到 Tailwind CDN、Google Fonts、Font Awesome CDN。這些只影響介面樣式與圖示，不會把影片素材上傳出去。

### 匯出按鈕不能按

請先上傳影片。影片載入完成後，匯出按鈕才會啟用。

### 只能輸出 WebM，不能輸出 MP4

這取決於瀏覽器是否支援 MP4/H.264 的 `MediaRecorder`。若瀏覽器不支援，程式會退回 WebM。

### 匯出很慢或畫面卡

4K、高碼率或長片段都會提高瀏覽器負擔。可以先縮短剪輯範圍、保持流暢優先開啟、關閉其他吃效能的分頁，並避免電腦進入省電模式。

### 音量太大或爆音

先降低原聲或音樂音量，再開啟 Dynamic Limiter。Limiter 主要用來防止瞬間過載，不適合拿來修復已經破掉的音訊。

## 開發備註

此專案沒有建置流程，也沒有套件安裝步驟。修改後直接重新整理瀏覽器即可看到結果。

- 修改畫面結構：編輯 `index.html`
- 修改版面與響應式：編輯 `styles.css`
- 修改功能邏輯：編輯 `app.js`

如果之後要真正離線使用，可以把 Tailwind、Font Awesome、字體資源改成本機檔案，避免 CDN 依賴。
